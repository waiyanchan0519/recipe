1. 專案總覽 (Overview)

美味食譜 (RecipeApp) 是一個為現代 Android 平台量身打造的原生開源 App。它擺脫了傳統雜亂網頁食譜的廣告與冗贅故事，專注於料理者在廚房備料與烹煮時的實際需求。

🚀

現代純 Kotlin 技術棧

100% 使用 Kotlin 撰寫，宣告式 UI 框架 Jetpack Compose，無任何傳統 XML 佈局包袱。

📐

Material 3 暖色食慾美學

量身調配陶土橘（Terracotta）與琥珀黃的主題調色板，完美支援深色模式（Dark Mode）。

⚡

零外部重度相依

採用輕量穩健的單向資料流（UDF）與 StateFlow，啟動速度飛快，不佔用多餘手機記憶體。

2. 核心特色 (Key Features)

01

多元菜系探索與即時關鍵字搜尋

內建台式經典滷肉飯、日式滑蛋嫩牛丼、義式蒜香白酒蛤蜊麵、正宗泰式打拋豬、法式生巧布朗尼、彩虹酪梨煎蝦沙拉等。支援以菜名、食材（如：蛤蜊、五花肉）或料理標籤即時篩選。

02

智慧份量動態換算 (Dynamic Servings Adjuster)

不管是 1 人獨享還是 6 人家庭聚餐，在食譜頁自由調整份量（1~20 人份），所有食材的公克數、匙數、顆數均會透過內建演算法精確倍率縮放與四捨五入格式化。

03

料理步驟引導與整合烹調計時器 (Cooking Timer)

每個步驟清楚標註火候要點與主廚秘訣。需要精準掌握時間的步驟（如燉煮 45 分鐘、煸香 3 分鐘），可一鍵啟動環狀倒數計時器，支援背景倒數、暫停/繼續、追加時間與完成提示。

04

一鍵匯入超市備料清單 (Smart Shopping List)

確認完用餐人數後，點擊「加入備料清單」即可自動將換算後的食材整批匯入購物車。採買時逐項勾選打勾，並支援「一鍵清除已購」功能。

5. 核心資料模型 (Data Models)

所有資料實體均以 Kotlin data class 與 enum class 嚴格規範，不可變性（Immutability）保證多執行緒安全：

Recipe.kt (精華程式碼展示) 
data class Ingredient(
    val name: String,
    val baseAmount: Double,
    val unit: String,
    val note: String = ""
) {
    // 智慧換算：依據份量倍率 (multiplier) 格式化輸出
    fun getFormattedAmount(multiplier: Double): String {
        val calculated = baseAmount * multiplier
        return if (calculated <= 0.0) {
            ""
        } else if (calculated % 1.0 == 0.0) {
            calculated.toInt().toString()
        } else {
            String.format("%.1f", calculated).trimEnd('0').trimEnd('.')
        }
    }
}

data class CookingStep(
    val stepNumber: Int,
    val title: String,
    val description: String,
    val timerMinutes: Int? = null,  // 若步驟需要計時，填入分鐘數
    val tip: String? = null          // 大廚關鍵提點
)

data class Recipe(
    val id: String,
    val title: String,
    val subtitle: String,
    val description: String,
    val category: Category,
    val emoji: String,
    val prepTimeMinutes: Int,
    val cookTimeMinutes: Int,
    val defaultServings: Int = 2,
    val difficulty: Difficulty,
    val calories: Int,
    val rating: Double,
    val reviewCount: Int,
    val tags: List<String>,
    val ingredients: List<Ingredient>,
    val steps: List<CookingStep>,
    val chefTips: List<String>
)

6. 狀態管理 (ViewModel & StateFlow)

在 RecipeViewModel.kt 中，所有的 UI 狀態透過單一資料流 StateFlow<RecipeUiState> 暴露給 Compose 視圖層，狀態切換均透過可預測的純函式 _uiState.update { ... }：

RecipeViewModel.kt - 計時器協程實作 
private fun runTimerCountdown() {
    timerJob = viewModelScope.launch {
        while (true) {
            delay(1000L) // 每秒精準遞減
            val currentRemaining = _uiState.value.timerState.remainingSeconds
            if (currentRemaining > 1) {
                _uiState.update {
                    it.copy(timerState = it.timerState.copy(remainingSeconds = currentRemaining - 1))
                }
            } else {
                _uiState.update {
                    it.copy(
                        timerState = it.timerState.copy(
                            remainingSeconds = 0,
                            isRunning = false
                        )
                    )
                }
                break
            }
        }
    }
}

8. 快速開始與編譯 (Getting Started)

Step 1

安裝環境需求

  • 作業系統: Windows 10/11, macOS, 或 Linux
  • 開發工具: Android Studio (建議 Iguana / Jellyfish / Ladybug 或更高版本)
  • JDK 版本: Java 17 或 Java 21 (由 Gradle Foojay 工具鏈自動偵測下載)
Step 2

複製 Git 專案

PowerShell / 終端機 
git clone git@github.com:waiyanchan0519/recipe.git
cd recipe
Step 3

以 Android Studio 開啟

  1. 啟動 Android Studio，在歡迎畫面點選 Open。
  2. 選擇 C:\RecipeApp 資料夾。
  3. Android Studio 將自動進行 Gradle Sync。
  4. 連接手機（開啟 USB 偵錯）或啟動 Android 模擬器 (AVD)。
  5. 點選右上角綠色三角形 Run 'app' (Shift + F10) 即可執行！
Step 4

命令列建置 APK (Command Line Build)

Windows PowerShell 
# 編譯 Debug APK
.\gradlew assembleDebug

# 編譯輸出路徑位於：
# app/build/outputs/apk/debug/app-debug.apk

9. 常見問題 (FAQ)

Q: 可以在舊款 Android 手機上執行嗎？

可以！專案的 minSdk 設定為 24 (Android 7.0 Nougat)，涵蓋全球超過 98.8% 的活躍 Android 裝置。

Q: 如何在 GitHub Pages 託管此文件網站？

本文件網站位於 /docs 資料夾中。在 GitHub 儲存庫頁面依序點選 Settings -> Pages -> Build and deployment，將 Branch 設為 main，資料夾選擇 /docs，點擊 Save 後即可於 https://waiyanchan0519.github.io/recipe/ 免費上線！

Q: 計時器在背景會繼續倒數嗎？

計時邏輯是由掛載於 ViewModel 上的 Kotlin Coroutine Job 管理，在同一個 App 生命週期內切換分頁或詳情頁均會保持持續倒數，並於歸零時觸發震動通知提醒。
